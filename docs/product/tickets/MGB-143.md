# MGB-143 — Improve guidance layout and visual priority

**Type:** UX enhancement
**Priority:** Medium
**Depends on:** MGB-142

## Problem

Once guidance exists, analysts still have to hunt for the next step. Urgent payments should read first.

## Request

Refine the resolution guidance card:

- Give the card more visual weight than the surrounding facts.
- Put the next step above secondary detail.
- Present required information as a short checklist.
- Make an approval or escalation requirement obvious.
- Keep the text readable and the control accessible.

This is a visual refinement of the component added in MGB-142. The baseline does not include it.
